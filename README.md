# College Placement System

Software Engineering mini project by Sourabh Rajput (EN24CS3011016), B.Tech CSE, Medi-Caps University.

## Features
- Student: save profile (name, enrollment, CGPA), view open drives, apply with automatic CGPA eligibility check, track status.
- Placement Officer: post drives, view applicants, set status (Applied, Shortlisted, Selected, Rejected), remove drives.
- Dashboard counts: drives open, applications, students placed.

## Technologies
HTML5, CSS3, JavaScript, browser localStorage, Git and GitHub Pages.

## How to run
Open `index.html` in any modern browser. No installation or server is needed.

## How to deploy on GitHub Pages
1. Upload `index.html` to a public repository.
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Open the link shown on the Pages screen.
